# اپلیکیشن Android سامانه رزرواسیون غذا - فولاد افزا سپاهان
این پروژه یک WebView است و نسخه آنلاین سامانه را داخل اپلیکیشن نمایش می‌دهد.

در فایل app/src/main/java/com/fooladafza/food/MainActivity.java مقدار APP_URL را با آدرس واقعی سامانه روی هاست جایگزین کنید.

Workflow ساخت APK در .github/workflows/build-apk.yml قرار دارد.
